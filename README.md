# In Living Color: Sketch Wars — update feed

This repository hosts the update feed for the free, unofficial fan game *In Living Color: Sketch Wars*. The game checks `https://tre2k3.github.io/ilc-sketch-wars-updates/updates/stable/` for new versions; installers are attached to this repository's Releases.

Not affiliated with, endorsed by, or connected to *In Living Color*, its creators, network or cast.
